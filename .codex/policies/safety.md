# Safety Policy

## Allowed Without Per-Step Approval
- Read, create, and edit files in this repository.
- Run local terminal commands for setup, verification, and implementation.
- Create or update GitHub issues.
- Add labels and status notes.
- Create commits and push verified changes to `origin/main`.
- Update shared Codex memory.

## Not Allowed Autonomously
- Force push.
- Delete production code.
- Delete project history.
- Publish secrets.
- Claim tests, builds, deploys, or audits passed when they did not run.

## Required Behavior
- Prefer reversible changes.
- Keep work scoped to the selected issue.
- Stop and record a blocker when credentials, auth, or external tools are unavailable.
- Push to `origin/main` only after required verification passes.
